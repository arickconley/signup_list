## Agent skills

### Issue tracker

Issues and PRDs use GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default canonical triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout. See `docs/agents/domain.md`.

## Frontend

Use project-owned Blade components, Tailwind CSS, and Livewire. Do not add Flux or another UI component library without an explicit architecture decision.
